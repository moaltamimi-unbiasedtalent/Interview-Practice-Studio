# Knowledge Source Catalogue

Authoritative sources configured for Career Intelligence, grouped by data
type. **Lifecycle is measured from the local stores** (see
`data/source_status.json`, regenerated by `python scripts/source_status.py`):
a source in this catalogue is *configured*, not necessarily loaded. No
third-party datasets are committed to the repository.

## Summary

- Configured sources: **25**
- Available for retrieval (loaded locally): **16**
- Manual acquisition required: **17**
- Licence review required: **15**
- Structured records loaded (offline samples): **53**

Authority level is retrieval metadata (1 official · 2 public framework ·
3 industry), **not** a truth score.

## Storage routing

- **Structured stores (SQLite)** — occupations/skills/tasks (`roles.db`),
  competencies/behaviours/qualifications (`competencies.db`), pay statistics
  (`compensation.db`), labour-market forecasts/openings/shortages
  (`labour_market.db`).
- **Vector store (Chroma)** — narrative/methodology only (handbooks, WEF).
- Structured data is never dumped into the vector store; narrative is never
  forced into tables. The router (`src/copilot/knowledge/router.py`) selects
  the lane per question.

See `docs/source_licensing.md` for the licensing audit and
`docs/rebuild_knowledge_base.md` for reproduction.

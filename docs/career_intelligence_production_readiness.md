# Career Intelligence — Production Readiness Report

Final readiness assessment for the Career Intelligence module (CI-PH1–PH6).
Numbers are measured and regenerated by `python scripts/gen_metrics.py`;
see [metrics_snapshot.md](metrics_snapshot.md) for the live snapshot and
[career-intelligence architecture](knowledge_architecture.md) for the design.

## Architecture (end-to-end)

User → input validation + security scan → intent + query translation →
occupation resolution + geography detection → deterministic lane router →
structured (roles/competency/compensation/labour-market/credentials) +
vector/BM25 + company/current context → geographic source precedence →
evidence merge → tools → grounded synthesis → citations → PreparationContext
→ Interview Practice. Every fact is cited; a gap is stated, never guessed.

## Known failures

From `evaluations/product_coverage/failures.md` (ranked remediation there):
- `industry_context` — no industry-of-employment dataset loaded (O*NET industry
  matrix / BLS Table 1.9 not ingested).
- Occupation-specific **shortage** queries below CLSSI's ISCO 2-digit granularity
  return an honest gap.
- Occupation resolution is lexical (title/alias), so unusual phrasings may need
  a clarification round.

## Known limitations

- **Fixture-only** competency/credential samples (e-CF, BA Kompetenzkatalog, OPM
  qualification standards, certifications/licences) are marked and never
  production-ready until real extracts are loaded.
- **DE/EU compensation** and per-occupation vacancy breakdowns are not loaded
  (Entgeltatlas manual; Eurostat JVS is country-level).
- Offline **lexical** embedder by default; semantic quality needs a dedicated
  embedding key (the benchmark relabels itself when one is set).
- Company context is user-supplied and time-stamped; live web search is behind
  a provider interface (null by default).

## Verdict

**PRODUCTION-DEMO READY.**

The retrieval system answers the breadth of candidate preparation questions
from real, cited, provenance-tagged sources, with honest gaps and passing
acceptance gates on the offline benchmark. This is a **demo/review** verdict —
it is **not** a claim of commercial production readiness, which additionally
requires operational hardening, privacy/data-retention controls, hosting, a
production embedding/LLM provider, and confirmed source licences. Those are
out of scope for this sprint and listed above.
